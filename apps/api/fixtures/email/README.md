Sample receipts for the email import demo (`POST /api/email/demo/import`).
They are invented test data in the shape of common Indonesian receipts, not real emails.
07 and 08 are payment notifications from other banks (Livin' by Mandiri, Bank Jago).
05 (promo) and 06 (personal mail from a non-allowed sender) must be ignored.
09-11 cover Livin' transfer (not spending), failed payment (ignored) and incoming funds (income).
12-14 cover Gmail's Purchases category: an unlisted IDR receipt (imported as 'perlu dicek'), a shipping update (ignored) and a USD receipt (ignored).
